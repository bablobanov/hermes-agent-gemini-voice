# Hermes Agent Gemini Voice

![Hermes Agent Gemini Voice](assets/hero.png)

[English](README.md) · [简体中文](README.zh-Hans.md) · [Безопасность](SECURITY.md) · [Изменения](CHANGELOG.md)

Голосовые поручения вашему Hermes Agent из **приложения Gemini на Android-телефоне**: на ходу, за рулём, не открывая
чат. Скажите *«Создай документ: Гермес, сравни три самых дешёвых рейса в Берлин на пятницу»*. Hermes найдёт документ,
сделает работу своими обычными инструментами и навыками и запишет ответ в тот же документ. Потом попросите Gemini
*«Прочитай документ Гермес рейсы»* и послушайте.

Без нового приложения, без ключа Gemini API и без публичного адреса: канал - это ваши собственные Google Календарь,
Документы и Таблицы. Hermes читает их своим OAuth-токеном плагина, а Gemini зачитывает вслух.

```text
приложение Gemini ──создаёт──► событие / документ / таблица с меткой в названии (ваш аккаунт)
                                       │ плагин опрашивает раз в минуту
                                       ▼
            gemini-voice ──поручение──► шлюз Hermes (один чат, ваши обычные инструменты и правила)
                                       │ финальный ответ
                                       ▼
            ответ записывается в тот же объект ──► «Прочитай документ …» в Gemini
```

## Что умеет

- **Поручения.** Новое событие Google Календаря, документ или таблица, в названии которых есть слово-метка (по
  умолчанию `Hermes`), становится сообщением Hermes. Плагин сначала пишет `[Hermes] принял, работаю`, потом заменяет
  это на `[Hermes] ответ:` и сам ответ
- **Дайджесты.** Любое cron-задание Hermes может доставить результат в новый документ (`gemini_voice:doc`) или в
  событие к нужному времени (`gemini_voice:event-0800`), и утренний брифинг становится вопросом *«Что у меня в 8?»*
- **Один разговор.** Все голосовые поручения идут в один чат, как личка в мессенджере. Если Hermes нужно ваше
  решение, он спрашивает в ответе, а вы отвечаете новым поручением
- **Только ваши объекты.** Приглашения, документы, которыми с вами поделились, и события, которые другие люди
  добавили в ваш календарь, игнорируются, даже если метка есть в названии (раздел [Безопасность](#безопасность-и-раскрытие))

### Как ведёт себя приложение Gemini (проверено автором, октябрь 2026)

- Одно поручение = один новый объект, одной фразой: *«Создай документ Гермес … с текстом …»*, *«Создай событие на
  завтра в 10: Гермес …»*, *«Создай таблицу Гермес покупки: молоко, хлеб, сыр»*
- Gemini не умеет править существующий документ и добавлять строку в существующую таблицу, поэтому разговор
  продолжается новыми объектами
- Gemini сам не сообщает, что ответ готов: вы спрашиваете, когда удобно. Для событий работает естественный вопрос:
  *«Что у меня завтра в 10?»*

## Что нужно

- Hermes Agent **0.21.6 или новее** с запущенным шлюзом сообщений (плагин - это платформа шлюза)
- Аккаунт Google, который используется в приложении Gemini на телефоне
- Свой проект Google Cloud для этого аккаунта (бесплатно) с включёнными **Google Calendar, Google Drive, Google Docs
  и Google Sheets API** и **OAuth-клиентом типа «Desktop app»**
- На экране согласия OAuth нажмите **Publish app** (статус «In production»). В статусе «Testing» Google отзывает
  refresh-токены через 7 дней, и канал молча перестанет работать через неделю. Для своего аккаунта подходит и
  непроверенное приложение: предупреждение Google «непроверенное приложение» появится один раз при согласии

## Установка

1. Поставьте и включите плагин (из каталога или клоном этого репозитория: папку `plugins/gemini-voice` скопировать
   в каталог плагинов Hermes):

   ```sh
   hermes plugins install gemini-voice
   hermes plugins enable gemini-voice
   ```

2. Один раз выдайте плагину собственный доступ к Google в терминале на машине Hermes. Держите под рукой JSON
   OAuth-клиента или вставьте ID и секрет клиента, когда команда спросит:

   ```sh
   hermes gemini-voice auth --client-secret-file <PATH_TO_CLIENT_JSON>
   ```

   Команда напечатает ссылку согласия Google. Откройте её в браузере под аккаунтом с телефона, разрешите все четыре
   доступа, затем скопируйте адрес страницы, которая не откроется (`http://localhost:1/…`), и вставьте обратно.
   Команда сохранит `GEMINI_VOICE_CLIENT_ID`, `GEMINI_VOICE_CLIENT_SECRET` и `GEMINI_VOICE_REFRESH_TOKEN` в `.env`
   Hermes и не выведет на экран ни одного секрета.

3. Проверьте и перезапустите шлюз обычным для вас способом:

   ```sh
   hermes gemini-voice check
   ```

   Ожидается: `TOKEN_OK scopes: calendar.events.owned drive.metadata.readonly documents spreadsheets` и `OK` для
   Calendar, Drive, Docs и Sheets API.

4. Необязательные настройки в `config.yaml` (значения по умолчанию):

   ```yaml
   plugins:
     entries:
       gemini-voice:
         settings:
           labels: [Hermes]          # "Гермес*" совпадает с любым словом, начинающимся на "Гермес"
           language: en              # en | ru, язык служебных строк плагина
           timezone: UTC             # имя пояса IANA для времени в статусах и доставки event-HHMM
           poll_seconds: 60
           max_age_hours: 24         # более старые объекты никогда не считаются поручениями
           answer_timeout_minutes: 40
           max_tasks_per_day: 30
           sources: [calendar, docs, sheets]
   ```

   Голосовые поручения выполняются с набором инструментов платформы, он настраивается как у любой другой платформы
   (`platform_toolsets.gemini_voice`, по умолчанию `hermes-gemini_voice`). Чтобы голосом было доступно то же, что в
   основном чате, дайте ему тот же набор.

## Как пользоваться

| Сказать Gemini | Что произойдёт |
|---|---|
| «Создай документ: Гермес, набросай ответ арендодателю про отопление» | Hermes напишет черновик в документ |
| «Создай событие на завтра в 9: Гермес, что взять с собой в паспортный стол» | ответ появится в описании события |
| «Создай таблицу Гермес расходы: бензин 3000» | Hermes выполнит и ответит строками ниже |
| «Прочитай документ Гермес арендодатель» / «Что у меня завтра в 9?» | Gemini зачитает ответ |
| «Создай документ: Гермес, да, отправляй» | ответ на вопрос, который Hermes задал в прошлом ответе |

Доставка вывода cron-задания в «голосовую» цель:

```sh
hermes cron create "30 7 * * *" "Morning briefing: mail, calendar, tasks" \
  --name "Briefing" --deliver gemini_voice:event-0800 --failure-deliver local
```

`gemini_voice:doc` создаёт новый документ, его название - первая строка вывода. `gemini_voice:event-HHMM` создаёт
15-минутное событие на это местное время (повторная доставка в тот же день его обновляет).

## Безопасность и раскрытие

- **Сеть:** только API Google (Calendar, Drive, Docs, Sheets) и `oauth2.googleapis.com`, на каждый опрос и на каждое
  поручение. Телеметрии нет, других адресов нет
- **Credentials:** плагин использует только свой OAuth-клиент и refresh-токен из трёх переменных `GEMINI_VOICE_*`.
  Чужие файлы токенов он никогда не читает. Access-токены живут только в памяти; единственная запись credentials -
  команда `hermes gemini-voice auth`, которую запускаете вы, через штатную функцию записи `.env` в Hermes
- **Доступы Google:** `calendar.events.owned`, `drive.metadata.readonly`, `documents`, `spreadsheets`. Без Gmail и без
  полного доступа к Drive. Плагин читает метаданные файлов, чтобы находить новые объекты, читает текст объектов с меткой
  и пишет только в объекты-поручения и в объекты, которые создаёт его cron-доставка
- **Кто ставит поручения:** тот, кто может создавать объекты в этом аккаунте Google, то есть обычно тот, у кого в руках
  ваш телефон с Gemini. Считаются только объекты, созданные владельцем аккаунта: у события владелец должен быть и
  создателем, и организатором, без других гостей; документ и таблица должны принадлежать вам, не быть расшаренными и
  последним их должны были менять вы. Поэтому платформа зарегистрирована как `trusted_inbound`: события приходят из
  аккаунта Google, который вы авторизовали, а не от других людей
- **Те же инструменты и правила, что в других чатах.** Плагин не добавляет своих одобрений и не обходит чужих. Команду,
  которой нужно одобрение человека, голосом одобрить нельзя, поэтому Hermes в этом канале её отклоняет; повторите такую
  просьбу в мессенджере. `clarify` на этой платформе заблокирован: посреди хода ответить некому
- **Фоновая работа:** задача опроса внутри процесса шлюза, пока платформа подключена
- **Не больше одного раза:** каждый объект записывается в журнал до передачи шлюзу; после рестарта поручение заново
  не запускается. Прерванный ход Hermes доводит сам, иначе через `answer_timeout_minutes` в объекте появляется пометка,
  что поручение не завершено
- **Без человека:** отозванный или истёкший токен никогда не открывает браузерный вход. Платформа сообщает
  `retrying / auth_failed` в статусе шлюза (`gateway_state.json`, `hermes gateway status`), пишет одну строку в лог,
  перепроверяет раз в 15 минут, а шлюз продолжает работать

## Статус и неполадки

```sh
hermes gemini-voice status   # статус платформы, последний успешный опрос, счётчики поручений (без названий и текста)
hermes gemini-voice check    # токен, доступы и четыре API
```

| Код | Что значит и что делать |
|---|---|
| `auth_failed` | токен отозван, истёк или без нужного доступа: `hermes gemini-voice auth`, затем рестарт шлюза |
| `google_unreachable` | сбой сети или Google: повтор с паузой до 15 минут |
| `api_disabled` | включите четыре API в проекте Cloud OAuth-клиента |

Ограничения: один аккаунт Google на профиль Hermes и один опрос на аккаунт; в таблице ответ пишется в столбец A
первого листа; в описании события ответ не длиннее 7000 символов; по умолчанию не больше 30 поручений в сутки.

## Тесты

```sh
python -B -m unittest discover -s plugins/gemini-voice/tests -t plugins/gemini-voice/tests -v
```

Юнит-тесты идут без сети и без Hermes, на эмуляторе Google в памяти. Необязательный контрактный тест загружает плагин
через настоящий checkout Hermes и без него пропускается (пропуск - не прохождение):

```sh
GEMINI_VOICE_TEST_ENGINE_ROOT=<HERMES_CHECKOUT> GEMINI_VOICE_TEST_ENGINE_PYTHON=<HERMES_PYTHON> \
  python -B -m unittest discover -s plugins/gemini-voice/tests -t plugins/gemini-voice/tests -p test_engine_contract.py -v
```
